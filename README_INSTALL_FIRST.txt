SAWTI 2.2 FOR MAC STUDIO (APPLE SILICON)

1. Extract ZIP, then right-click INSTALL_SAWTI.command > Open.
2. Approve one-time official Ollama and Qwen3 4B download. Internet required for setup.
3. After installation, right-click START_SAWTI.command > Open.
4. Open http://127.0.0.1:8765 and switch Sawti ON.
5. Switch OFF to release Sawti monitoring and stop Sawti-managed Ollama.

The installer downloads Ollama and Qwen. They are not physically in this ZIP.
It does not install optional speech transcription or voice identity models.
No Audition, Zoom, Scarlett, BlackHole, or existing Ollama settings are changed.
STOP: Switch OFF in Sawti, then Control+C in Terminal for complete application exit.
This is a developer prototype, not a signed/notarised macOS app.
