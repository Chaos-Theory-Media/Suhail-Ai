        Save the show template (first time, or after changing tracks)

          (plus a stereo “Zoom guests” track for Zoom shows), set each track's input, arm them (R), and save it.
          Then paste the path of that .sesx file here (drag the file into this box).

    Live levels
    
        
    
          
          
          
        
    
      
    
      
    
      
    
      
    
        
    
        
    
          
          
        
    
      
    
      
    Target while recording: speech around −20 LUFS on each mic, peaks under −6 dBFS, never red.
        The finished episode is mastered to −16 LUFS / −1 dBTP afterwards.
    
    
    

    
    
    
      
    Mix & master
    
      
    Sawti levels each speaker, closes mics that only carry someone else's voice, mixes, then masters
        to the house standard. Originals are preserved; each job writes _mix.wav and _master.wav files in a new Sawti-Export folder.

    Local AI models
    
      
    The enhanced profile is designed for the M1 Ultra with 128 GB. Downloads happen only in the installer. Switch Sawti OFF before changing the chat model. Enhanced inference is held during Live until Mac audio performance is qualified; built-in level checks remain available.
    
      
      
    
      
    Refresh to see downloaded models.
    
      
    Local reference library
    
      
    Import manuals or reviewed studio notes you are entitled to use. References stay local; they do not authorise actions. Use Ask manuals in chat for a combined answer with sources. Up to 400 passages; split large manuals into relevant chapters.
