Audition session

Save the show template (first time, or after changing tracks)

In Audition: create a 48 kHz multitrack session, add one mono track per mic (plus a stereo “Zoom guests” track for Zoom shows), set each track's input, arm them (R), and save it. Then paste the path of that .sesx file here (drag the file into this box).

Pre-test

A guided sound check: every microphone, talkback, the Zoom guest and a test recording. Sawti listens and tells you exactly which knob to turn.

    Live levels

    Target while recording: speech around −20 LUFS on each mic, peaks under −6 dBFS, never red. The finished episode is mastered to −16 LUFS / −1 dBTP afterwards.

    Mix & master

    Sawti levels each speaker, closes mics that only carry someone else's voice, mixes, then masters to the house standard. Originals are never changed; new files end in _mix.wav and _master.wav.

    Settings

    Microphone names (shown on meters and in coaching)

    Inline leveler (advanced, off by default)

    When ON, Sawti sits between the Scarlett and Audition: it rides each mic's level live and sends the levelled mics to the device below (use BlackHole 16ch), and the Audition template must record from that device. Test it outside live shows first. When OFF, Sawti only coaches and masters afterwards.

    Presenter voices (optional)

    Only with the presenter's consent. A voice signature is a convenience label, not security.
